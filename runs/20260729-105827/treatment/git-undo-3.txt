Use a soft reset. It undoes the commit and keeps every change staged in your working tree:

```bash
git reset --soft HEAD~1
```

What happens:

1. Git moves the branch pointer back one commit.
2. The changes from that commit stay staged, ready to edit or commit again.

Related options:

- `git reset HEAD~1` (same as `--mixed`): keeps the changes but unstages them.
- `git reset --hard HEAD~1`: discards the changes. Avoid this unless you want to lose the work.

If you already pushed the commit to a shared branch, use `git revert HEAD` instead. It creates a new commit that undoes the old one, which is safe to push without rewriting history.
